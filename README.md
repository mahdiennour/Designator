Drafting Table — a full house builder with two modes:
Build: pick a room type from the palette to drop it onto the lot, then drag it to move, drag the corner handle to resize, rename it, and set which wall the door sits on. Everything snaps to a half-foot grid on a blueprint-style canvas, with live square footage.
Decorate: switch a room from a blueprint outline into a real space — pick wall color and flooring (wood, tile, carpet, or concrete, each with its own texture), then drag furniture in from a categorized catalog (18 pieces from beds to stoves), rotate or delete any piece with one click.
It loads with a 6-room starter home already laid out, and your changes autosave as you go (bottom-right indicator), so it's there when you come back.
